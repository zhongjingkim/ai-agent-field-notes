# AI Agent Field Notes

Field notes from applying AI coding agents and multi-agent orchestration to real engineering workflows.

I am exploring a practical question:

> What must be true before a human can safely delegate long-running development work to an AI team?

My focus is not only whether an agent can write code. I am interested in whether a system can:

* coordinate multiple coding agents;
* make execution observable;
* verify claimed completion with evidence;
* detect deviation and request rework;
* preserve state and recover from interruption;
* define clear points for human takeover.
